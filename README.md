# Dayflare

Joelle’s daily pulse — a personal planner for tasks, workouts, wellness nudges, and reminders.

## Live site

**https://joelle-y10.github.io/dayflare/**

## Run locally

```bash
# Option A — open the file directly
open index.html

# Option B — local server (recommended)
python3 -m http.server 8000
```

Then visit the address the server prints (often http://localhost:8000).
